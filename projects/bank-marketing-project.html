Bank Marketing Project

Ce projet porte sur la préparation, le nettoyage et l’exploration d’un jeu de données bancaire afin d’identifier des patterns utiles à l’analyse d’une campagne marketing.

Contexte

Le projet repose sur un dataset bancaire composé de variables socio-démographiques, financières et comportementales. L’enjeu principal est de rendre ces données exploitables et cohérentes pour une analyse ultérieure.

Objectif

L’objectif est de préparer une base de travail propre, de mieux comprendre la structure du dataset et d’identifier les éléments pertinents pour l’analyse de la réponse à une campagne marketing.

Résultats

Ce que le projet met en place

dataset propre

Préparation et nettoyage des données pour réduire les incohérences et faciliter l’exploitation.

structure claire

Organisation du projet avec séparation des données brutes, nettoyées, scripts et notebooks.

base d’analyse

Création d’un socle exploitable pour des analyses plus poussées ou pour une future modélisation.

Fonctionnement

Comment le projet est structuré

1. Données sources

Le dossier de données contient les fichiers bruts à partir desquels le projet est construit. Ces sources sont conservées séparément des versions transformées pour préserver la traçabilité.

2. Préprocessing & cleaning

Les scripts Python prennent en charge le nettoyage, la transformation et la préparation des colonnes nécessaires à une analyse plus robuste.

3. Exploration

Les notebooks permettent d’examiner la distribution des variables, les corrélations potentielles et les grandes tendances du dataset.

4. Structuration du repo

Le projet est organisé avec des dossiers dédiés aux données, aux scripts, aux notebooks et aux exports, afin de rendre le travail plus lisible et maintenable.
