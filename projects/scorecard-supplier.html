Supplier Scorecard

Conception d’une scorecard fournisseurs sous Power BI à partir de données industrielles anonymisées. Le projet permet d’évaluer les fournisseurs de matières, d’identifier les profils à risque et de soutenir une démarche d’amélioration continue à travers des indicateurs métier fiables.

Contexte

Le projet repose sur plusieurs sources de données liées aux fournisseurs de matières d’une entreprise industrielle. Les données provenaient de bases distinctes, avec des structures hétérogènes et des règles de gestion spécifiques. L’enjeu principal consistait à identifier les clés de rapprochement pertinentes, consolider les données et construire une base analytique exploitable pour le calcul des indicateurs métier.

Objectif

L’objectif était d’automatiser l’évaluation des fournisseurs afin de fiabiliser l’analyse, réduire la charge de traitement manuel et améliorer la capacité de pilotage. Le projet a permis de passer d’un processus lourd et partiellement manuel à une démarche plus rapide, plus robuste et beaucoup plus scalable.

Aperçus du projet

Modèle de données et dashboard final

Pour des raisons de confidentialité, le rapport complet n’est pas publié en ligne. Cette page présente toutefois deux vues représentatives du travail réalisé : la modélisation dans Power BI Desktop et un aperçu du résultat final.

Défis techniques

  • Rapprocher plusieurs sources de données hétérogènes autour de clés communes.
  • Nettoyer et transformer les données pour garantir la cohérence des analyses.
  • Construire un modèle Power BI robuste, lisible et maintenable.
  • Implémenter des mesures DAX conformes aux règles d’évaluation métier.
  • Sécuriser l’accès aux données via des règles de Row-Level Security (RLS).

Pourquoi ce projet n’a pas de repository public

Contrairement à d’autres projets de ce portfolio, celui-ci n’est pas associé à un dépôt GitHub public, car il a été réalisé à partir de données sensibles dans un contexte professionnel. Afin de respecter la confidentialité, seules la démarche, l’architecture analytique et quelques aperçus visuels anonymisés sont présentés ici.
